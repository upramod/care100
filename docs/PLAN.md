# Build plan

## Day 1. Working slice

1. Confirm the transplant center's sample requirements.
2. Enter requirements by recovery period and responsibility.
3. Add caregiver availability.
4. calculate gaps without hiding partial coverage.
5. Generate a review screen with assumptions and unresolved gaps.

## Data objects

- Requirement: recovery period, responsibility, frequency, center source.
- Caregiver: display name, relationship, availability, accepted tasks.
- Assignment: requirement, caregiver, time window, status.
- Gap: uncovered requirement, severity, proposed next action.
- Review plan: assignments, gaps, assumptions, review status.

## Safety boundary

Care100 organizes information. It does not decide eligibility, approve caregivers, provide medical advice, or claim that an alternative satisfies a transplant center's rule.

## Deferred

Patient accounts, clinical-system links, notifications, document uploads, and AI-generated alternatives. Validate the manual planning flow first.
